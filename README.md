# Website Symphony Rengganis Consultant (SRC)

Website resmi **PT Symphony Rengganis Konsultan**, konsultan kebijakan publik dan tata kelola pemerintahan yang berbasis di Bandung.

🌐 **Live:** [srconsultant.solutions](https://srconsultant.solutions)

## Isi website

- **Beranda**: pengenalan singkat SRC
- **Tentang & Founder**: profil perusahaan, founder, dan legalitas (AHU & NIB)
- **Layanan**: Project-Based Consulting, Facilitation & Mediation, Capacity Building, Policy Evaluation
- **Tim Kami**: profil associate (klik kartu untuk detail)
- **Nilai**: nilai-nilai perusahaan
- **Kontak**: form konsultasi (via Formspree), WhatsApp, email, Instagram

## Struktur folder

```
SRC-website/
├── index.html      # seluruh halaman website
├── images/         # foto tim & gambar share (og-image.jpg)
└── README.md
```

## Teknologi

- HTML satu halaman
- [Tailwind CSS](https://tailwindcss.com) (via CDN)
- [Font Awesome 6](https://fontawesome.com) untuk ikon
- Google Fonts: Playfair Display & Inter
- [Formspree](https://formspree.io) untuk form kontak

## Cara mengubah konten

1. Buka `index.html` di GitHub, lalu klik ikon pensil (Edit).
2. Ubah teks yang diinginkan.
3. Di kolom **Commit message**, tulis perubahan dengan jelas, misalnya:
   - `Tambah profil associate baru: Budi`
   - `Perbarui daftar layanan`
   - `Ganti foto founder`
4. Klik **Commit changes**.

## Menambah atau mengganti foto tim

1. Kecilkan dulu fotonya (lebar maks. ±900 px, ukuran di bawah 200 KB), misalnya lewat [squoosh.app](https://squoosh.app).
2. Beri nama huruf kecil tanpa spasi, contoh: `images/nama-orang.jpg`.
3. Upload ke folder `images/` (Add file → Upload files).
4. Di `index.html`, arahkan `src` foto ke `images/nama-orang.jpg`.
